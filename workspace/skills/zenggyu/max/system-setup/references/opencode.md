# OpenCode

This is the reference file for OpenCode setup.

# Prerequisites

- Bun (the JavaScript, TypeScript & JSX toolkit) installed on system

# Official URLs

- Home page: <https://opencode.ai/>
- Github repo: <https://github.com/anomalyco/opencode>
- Plugins:
    - `oh-my-opencode` Github repo: <https://github.com/code-yeongyu/oh-my-openagent>

# Installation/Upgrade

Use `bun`, and prefer the latest version:

```bash
bun add -g opencode-ai@latest

```
